\# Employee Management CRUD App



This is a small task application built using \*\*Angular\*\* and \*\*.NET Core Web API\*\* for managing a list of employees. It includes the basic CRUD operations: Create, Read, Update, and Delete.



\## 🛠️ Technologies Used



\- Frontend: Angular 18 (Angular Material, Reactive Forms)

\- Backend: ASP.NET Core Web API

\- Database: In-Memory

\- Styling: Angular Material 

\- Export: PDF / Excel support

\- Features: Filtering, Validations



\## 🚀 Features



\- Add new employees with validation

\- Edit existing employee data

\- Delete employees with confirmation

\- View employee list in a styled Material Table

\- Filter employees by name

\- Paginate employee list

\## ▶️ Getting Started



\### Frontend (Angular)



```bash

cd client

npm install

ng serve

```



\### Backend (.NET Core)



```bash

cd server

dotnet build

dotnet run

```



\### Open in browser



Visit: `http://localhost:4200`
